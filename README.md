ECE 362 FINAL PROJECT - EWI

A digital sampler electronic wind instrument in the control style of a euphonium.

Protocols / Peripherals
- ADC: Analog barometric pressure sensor reads breath input to act as mouthpiece.
- SPI: Allows SD card reader to store sound source files and communicate with the MCU.
- I2C: Allows DAC to communicate with MCU before outputting to stereo speaker amplifiers.
- PWM: Control LED vector as output level meter.
